Guía de entornos Python

InicioManualRepositorio

Entornos virtuales y primeros pasos reproducibles.

1. Crea tu entorno

python -m venv .venv

Windows PowerShell

.venv\Scripts\python.exe -m pip --version

Linux

.venv/bin/python -m pip --version

Puedes usar el intérprete del entorno directamente sin cambiar la política de ejecución de PowerShell.

2. Ejecuta el ejemplo

python examples/hola.py

Al instalar paquetes, usa el Python de ese entorno con -m pip. Las carpetas .venv y las claves nunca se suben a Git.
