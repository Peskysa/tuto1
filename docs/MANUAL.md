# Manual · Guía de entornos Python

Crea un entorno con `python -m venv .venv`. No es necesario activar scripts: en Windows puedes usar directamente `.venv\Scripts\python.exe` y en Linux `.venv/bin/python`.

Ejecuta `python examples/hola.py`. Instala dependencias, cuando las necesites, mediante `python -m pip` del mismo entorno. Registra los paquetes de cada proyecto en su manifiesto y excluye .venv de Git.

Chuleta.docx y Virtualenv.docx se conservan sin modificar como apuntes históricos; no se da por actual todo su contenido ni se reasigna su autoría. Las instrucciones mantenidas son las de este manual y la web.
